Hermes Cornerstone

Support & operator contact

Help for the operator and explicitly approved Hermes Cornerstone team members.

Effective and last updated: October 26, 2026

Private team support

For access problems, personal information, account-specific requests, or data deletion, contact the Hermes Cornerstone administrator who invited or authorized you using the team’s existing Discord server or established communication channel. Ask for a private conversation with the operator, GitHub user susheel009.

The app is called Hermes; the bot identity supplied at publication is HermesBot#9321. The bot account is not a substitute for a human operator contact. This site does not publish a public server invitation or promise that unsolicited bot DMs reach the operator.

Public, non-sensitive support

Use the repository’s GitHub Issues page for general website or setup issues. A GitHub account is required to post. Include the affected page or feature and a short, redacted description of the problem.

GitHub issues are public. Never post access tokens, API keys, passwords, private transcripts, Discord user IDs, confidential files, or personal data. If you cannot reach the operator privately, post only a request for a private contact route.

Privacy and deletion

Follow the data-deletion instructions for erasure requests. For access, correction, provider information, or other privacy questions, use the same private operator route. See the Privacy Policy for the information the assistant can process.

Security issues

Report suspected unauthorized access or exposed credentials to the operator privately. Do not publish exploit details, screenshots containing secrets, or the credential itself. If a credential is compromised, the account owner should revoke or rotate it in the issuing service; removing a screenshot or Git commit alone is not enough.

Service expectations

This is a private deployment without a guaranteed support response time or uptime commitment. An offline bot may mean the operator’s computer or Hermes gateway is stopped, rather than a problem with these pages. The official Hermes setup guide covers the Discord gateway requirements.
